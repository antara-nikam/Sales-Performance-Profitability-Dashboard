
# Sales Performance & Profitability Dashboard

## Project Overview
An end-to-end data analytics project focused on analyzing sales performance and profitability using MySQL and Power BI. The project involves analyzing 9,994 sales records to identify business trends and evaluate performance across product categories, regions, and customer segments.

Using SQL queries, the data was explored to identify key business insights, including sales trends, profit margins, loss-making products, and the impact of discounts on profitability. An interactive Power BI dashboard was developed with KPIs, charts, and slicers to present findings and support data-driven business decisions.

## Tools & Technologies
- MySQL
- SQL
- Power BI
- DAX

## Key Analysis
- Sales and profit analysis
- Category-wise and regional performance
- Customer segment analysis
- Discount impact on profitability
- Identification of loss-making products

## Project Objectives
- Analyze overall sales and profitability.
- Identify business trends and performance patterns.
- Understand factors affecting profitability.
- Present insights through an interactive dashboard.
